# Shiny System - Sales Funnel Builder

A production-ready, enterprise-grade sales funnel builder built with React, Vite, XYFlow, and Zustand.

## Features

- **Visual Funnel Editor**: Drag-and-drop canvas for building sales funnels
- **Custom Nodes**: Landing Page, Lead Capture, Email Automation, AI Qualification, Payment, Conditions, Analytics
- **Real-time Analytics**: Track visitors, leads, conversion rates, and revenue
- **State Management**: Zustand for predictable state management
- **Testing**: Full test coverage with Vitest and React Testing Library
- **Responsive Design**: Mobile-friendly interface
- **API-Ready**: Clean service layer for backend integration

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Project Structure

```
src/
 ├── app/              # Application entry points
 ├── components/       # Reusable components
 ├── nodes/           # Custom flow nodes
 ├── store/           # Zustand stores
 ├── services/        # API and external services
 ├── hooks/           # Custom React hooks
 ├── types/           # TypeScript definitions
 ├── utils/           # Utility functions
 ├── tests/           # Test files
 └── styles/          # Global styles
```
